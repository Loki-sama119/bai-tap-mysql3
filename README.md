# Chuyển đổi ERD sang mô hình quan hệ

Bài tập CodeGym: xác định thực thể, chuyển đổi các quan hệ N–N và 1–N, xử lý thuộc tính đa trị và liệt kê các bảng quan hệ cuối cùng.

**Kết quả:** 5 thực thể gốc + 3 bảng cho quan hệ N–N + 1 bảng cho thuộc tính đa trị = **9 bảng**.
